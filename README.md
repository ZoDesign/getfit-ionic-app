# getfit-ionic-app
GetFit – Ionic Fitness App

GetFit is a mobile fitness tracking application built with Ionic, Angular, and TypeScript. Designed for a small health and wellness business, the app enables users to create an account, browse personalised workout programmes, view exercise details, and track their fitness progress over time. User data is stored locally using local storage, providing a lightweight and responsive experience.

# Motivation for project
Staying consistent with a fitness routine can be challenging without a simple way to track progress. GetFit was developed to help users manage their workouts by allowing them to browse exercises, record completed workouts, monitor their progress, and reset their workout history when starting a new fitness cycle. The project showcases my ability to design and develop intuitive, user-focused mobile applications.

------------------------------------------------------------
## 1. FEATURES
------------------------------------------------------------

### ✓ User Authentication
- Users can sign up and log in.
- Authentication is simulated using local storage.
- Login and signup forms use Ionic Input components.

### ✓ Workout Program Listing
- Users can browse a list of predefined workout categories 
  (Weight Loss, Muscle Gain, Cardio, etc.).
- Programs are managed using an Angular Workout Service.
- Workout programs displayed using Ionic List components.

### ✓ Workout Details
- When a workout is selected, the user navigates to a 
  dedicated details page.
- Details include:
  • Workout description  
  • List of exercises  
  • Duration and equipment needed  
- Users can mark workouts as completed.

### ✓ Progress Tracking
- Completed workouts are saved using Ionic Storage.
- A Progress page displays the user’s achievements.
- Users have an option to reset their progress.

### ✓ Navigation & UI
- App includes the following pages:
  • Home  
  • Workouts  
  • Workout Details  
  • Progress  
  • Login  
  • Sign Up  
- Navigation implemented using Ionic Router.
- UI built using Ionic components with custom SCSS styling.
